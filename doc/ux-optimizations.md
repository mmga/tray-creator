# UI/UX 体验优化与功能扩展建议

在仔细审视了目前的战锤托盘生成器 (Tray Creator) 项目目前的代码架构、UI 设计以及用户工作流后，我为您总结了以下几个维度的**用户交互体验 (UX) 优化**与**可扩展功能**。

---

## 1. 核心编辑器交互优化 (2D & 3D)

### 1.1 2D 自定义布局的高级工具 (Custom Mode)

目前的 2D 画布支持了拖拽、旋转和删除，但对于希望制作精密复杂托盘的高级用户来说，还有很大的体验提升空间：

- **网格吸附 (Snap to Grid)**: 提供一个“吸附到网格”的开关，让强迫症玩家能够轻松对齐各个孔位。
- **自动对齐/分布菜单 (Alignment Tools)**: 提供类似 Figma 的对齐工具（左对齐、居中、等距分布），在框选多个孔位后可以一键整理。
- **复制与粘贴 (Copy/Paste & Duplicate)**: 允许用户选中某个调整好角度的孔位，按 `Ctrl+C / Ctrl+V` 或 `Alt+拖拽` 直接复制出完全一样的孔位。

### 1.2 3D 渲染与预览优化 (Tray Viewer)

- **实时尺寸标注 (3D Dimensions)**: 在 3D 视图的外围动态渲染长宽高尺寸线 (类似 CAD 软件)，让长宽的感知更直观，而不是只看左侧的数字。
- **切片预览平面 (Clipping Plane)**: 允许用户拖动一个滑块从 Z 轴切开模型，查看底板预留磁铁孔的内部结构是否正确。

## 2. 性能与底层架构体验优化

### 2.1 Web Worker 异步渲染 (防止页面卡死)

- **痛点分析**: 目前使用 `@jscad/modeling` 进行 3D 实体的布尔运算（尤其是在生成几十个孔位的阵列时）是非常消耗 CPU 的。如果计算逻辑在主线程中运行，点击“开始锻造”时整个网页可能会发生几秒钟的假死（按钮点不动，动画卡住）。
- **扩展方案**: 引入 **Web Worker** 技术。将 `generateGridTray` 和 `generateCustomTray` 的底层计算放到 Worker 线程。主线程只需显示流畅的转圈动画和精确到百分比的进度条，计算完成后将几何体返回给主线程。这将是体验上的**质的飞跃**。

### 2.2 防抖动自动预览 (Auto-Preview)

- 对于耗时较短的小改动（如修改圆角大小、底板厚度），如果用户每次改完都要点一次“开始锻造”会很繁琐。
- 可以在开启 Web Worker 后，增加一个“自动更新”开关。用户拖动滑块一旦停下 (Debounce 500ms)，后台静默计算并无缝刷新右侧的 3D 模型。

## 3. 业务与用户工作流扩展 (Scalable Features)

### 3.2 动态成本/耗材预估 (Cost Estimation)

- 玩家或店主通常关心打印需要多少树脂或 PLA。
- **扩展方案**: `@jscad/modeling` 生成后，基于体积 (Volume) 计算方法，如果在左侧面板输入材料密度和单价（如 1g = 0.15元），系统可以自动在左下角的统计面板中输出：**“预计重量: 45g | 预计物料成本: 6.75元”**。这对有对外接单需求的使用场景极其有利。

### 3.3 移动端适配 (Mobile Responsiveness)

- 检查并优化移动端的排版，很多用户会直接在手机上调整参数和预览。
- 如果手机上进行 3D 渲染太费电，可以设定规则：**移动端访问时默认隐藏 3D 渲染（或者用占位图提示），仅保留纯数字配置面板或 2D 布局**，确保客户能够流畅提交配置。
