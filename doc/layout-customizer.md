# 布局自定义器（Layout Customizer）— 需求文档

> 文档创建日期：2026-02-14

## 1. 功能概述

在现有「参数化均匀网格」模式基础上，新增 **布局自定义器** 功能，允许用户在一个托盘中自由配置不同尺寸的凹槽。

**核心目标**：支持「混合编队」——同一托盘放置不同底座尺寸的微缩模型（例如步兵 + 英雄、步兵 + 骑兵）。

---

## 2. 需求分析

### 2.1 用户场景

| 场景         | 描述                                               |
| ------------ | -------------------------------------------------- |
| 混合编队托盘 | 一个托盘中需要 8 个 25mm 步兵位 + 1 个 40mm 英雄位 |
| 指挥组托盘   | 前排 3 个 32mm 标准步兵 + 后排 1 个 50mm 指挥官    |
| 载具 + 护卫  | 中间 1 个 60mm 大型模型 + 四周 6 个 25mm 护卫      |

### 2.2 与现有功能的关系

- **现有模式（「网格模式」Grid Mode）**：统一尺寸的行列网格，保持不变
- **新模式（「自定义模式」Custom Mode）**：通过二维网格编辑器，用户逐个格子选择凹槽尺寸或标记为空
- 两个模式通过 **顶部标签页（Tabs）** 切换

---

## 3. 功能设计

### 3.1 UI 入口 — 顶部标签页

在 Header 下方（`<main>` 上方）新增标签页栏：

```
┌──────────────────────────────────────────────┐
│                  Header                       │
├──────────────────────────────────────────────┤
│  [⬛ 网格模式]  [⬜ 自定义模式]                 │  ← 新增标签页
├──────────────┬───────────────────────────────┤
│  参数面板     │        3D 预览视口              │
│  (随模式变化) │                                │
└──────────────┴───────────────────────────────┘
```

- 默认选中「网格模式」，行为与当前完全一致
- 切换到「自定义模式」时，左侧参数面板内容替换为布局编辑器

### 3.2 自定义模式 — 左侧面板内容

#### 3.2.1 画布尺寸设置

用户设置「画布」的行列数（定义网格的最大范围）：

| 参数     | 说明               | 范围 |
| -------- | ------------------ | ---- |
| 画布列数 | 水平方向最大格子数 | 1–8  |
| 画布行数 | 垂直方向最大格子数 | 1–8  |

> 画布的每个格子占用 1 个「单位格」，大型凹槽可以占多个格子（见 3.2.3）。

#### 3.2.2 2D 网格编辑器

在参数面板内部展示一个可交互的 2D 网格：

```
┌────┬────┬────┬────┐
│ 25 │ 25 │ 25 │ 25 │
├────┼────┼────┼────┤
│ 25 │    40   │ 25 │   ← 40mm 凹槽占据 2×2 格子
├────┤         ├────┤
│ 25 │         │ 25 │
├────┼────┬────┼────┤
│ 25 │ 25 │ 25 │ 25 │
└────┴────┴────┴────┘
```

#### 3.2.3 格子操作

**基础交互**：

1. **点击格子** → 弹出尺寸选择面板（使用现有预设：25/28.5/32/40/50/60mm）
2. **选择尺寸后** → 格子显示对应直径，颜色按尺寸区分
3. **再次点击已填充的格子** → 清除该格子（标记为空）

**尺寸与格子的映射规则**：

| 底座直径 | 占用格子 | 说明                            |
| -------- | -------- | ------------------------------- |
| 25mm     | 1×1      | 单格                            |
| 28.5mm   | 1×1      | 单格                            |
| 32mm     | 1×1      | 单格                            |
| 40mm     | 2×2      | 占 4 格，格子必须都为空才能放置 |
| 50mm     | 2×2      | 同上                            |
| 60mm     | 3×3      | 占 9 格，格子必须都为空才能放置 |

> 简化设计：单位格的物理尺寸统一等于最大单格凹槽直径（32mm）+ 间距。大型凹槽按占用的格子区域居中放置。

#### 3.2.4 结构参数

自定义模式复用网格模式的以下结构参数（共享配置）：

- 间距 (spacing)
- 底板厚度 (baseThickness)
- 凹槽深度 (holeDepth)
- 圆角半径 (cornerRadius)

### 3.3 自定义模式 — 建模逻辑

自定义模式的 3D 模型生成：

1. **底板尺寸**：根据画布行列数和单位格大小计算
   - `totalWidth = columns × unitSize + (columns + 1) × spacing`
   - `totalDepth = rows × unitSize + (rows + 1) × spacing`
   - `unitSize = 32mm + HOLE_TOLERANCE`（最大单格凹槽直径 + 公差）
2. **外壳**：与网格模式相同，圆角矩形拉伸
3. **凹槽**：遍历布局数据，根据每个凹槽的位置和直径生成 cylinder 并做布尔减法

### 3.4 布局数据模型

```typescript
// 布局中的单个凹槽
interface LayoutSlot {
  /** 格子起始位置（0-indexed，左上角） */
  gridRow: number;
  gridCol: number;
  /** 占用的格子数（1×1, 2×2, 3×3） */
  gridSpan: number;
  /** 凹槽直径 (mm)，来自预设 */
  diameter: number;
}

// 自定义布局参数
interface CustomLayoutParams {
  /** 画布列数 */
  canvasColumns: number;
  /** 画布行数 */
  canvasRows: number;
  /** 凹槽列表 */
  slots: LayoutSlot[];
  /** 结构参数（复用 TrayParams 的部分） */
  spacing: number;
  baseThickness: number;
  holeDepth: number;
  cornerRadius: number;
}
```

## 4. 可行性分析

### 4.1 技术可行性

| 方面           | 评估    | 说明                                                      |
| -------------- | ------- | --------------------------------------------------------- |
| 2D 网格编辑器  | ✅ 可行 | 纯 React + CSS Grid 实现，无需额外依赖                    |
| 多尺寸凹槽建模 | ✅ 可行 | JSCAD 的 `cylinder()` 支持任意半径，遍历 slots 即可       |
| 标签页切换     | ✅ 可行 | 使用 shadcn/ui 的 Tabs 组件                               |
| 与现有代码共存 | ✅ 可行 | 新增独立的 createCustomTrayModel 函数，不修改现有建模逻辑 |
| 性能           | ✅ 可行 | 最大 8×8=64 格，凹槽数量远少于此，布尔运算在可接受范围内  |

### 4.2 设计约束 & 简化策略

1. **固定单位格尺寸**：所有格子物理尺寸相同（基于 32mm），大型底座占据多格
   - 优点：网格编辑器实现简单，格子对齐直观
   - 缺点：小底座（25mm）周围会留有间隙 → 可接受，不影响功能
2. **大型底座对齐**：大型底座必须对齐到 2×2 或 3×3 的格子块
   - 不支持跨行/列的任意偏移放置
3. **不支持旋转**：所有凹槽为圆形，无需旋转

### 4.3 风险与规避

| 风险                   | 规避措施                                    |
| ---------------------- | ------------------------------------------- |
| 大尺寸凹槽放置校验复杂 | 限制为 1×1、2×2、3×3 三种占用，校验逻辑简单 |
| 空格子过多导致底板浪费 | UI 中显示实际使用率，提示用户优化           |
| 切换标签页丢失状态     | 两个模式各自维持独立 state，切换不清除      |
