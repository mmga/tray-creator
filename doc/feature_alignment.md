在“完全自由拖拽”和“强迫对齐”之间，确实存在一个非常甜美的平衡点。既然我们放弃了全局网格吸附，那么引入**“智能辅助（Smart Assists）”**是最佳解决方案。

这就好比现在的 PPT 或 Figma，平时你可以瞎摆，但当你凑巧对齐了某个物体时，系统会告诉你。

以下是几种由易到难、针对战锤托盘场景特别有效的方案：

1. 智能对齐辅助线 (Smart Guides) —— 首选推荐
   这是目前最主流的交互方式（类似 Figma/PowerPoint）。

交互逻辑：

当你拖拽圆圈 A 时，系统实时计算它和圆圈 B、C、D 的圆心坐标。

如果 A 的 X轴 或 Y轴 坐标与 B 的坐标差值小于阈值（例如 2px）：

自动吸附：强制将 A 的坐标设为等于 B。

视觉反馈：在两个圆心之间显示一条虚线，告诉用户“现在是对齐的”。

适用场景：想摆一排横队，或者一个标准的三角阵。

开发难度：中等。只需要在 onDrag 时遍历一下其他圆的坐标即可。

2. 按键轴锁定 (Axis Locking via Shift Key) —— 性价比最高
   这是一个几乎所有设计软件通用的“潜规则”，用户不需要学习成本。

交互逻辑：

用户按住圆圈开始拖拽。

如果在拖拽过程中按住了 Shift 键。

系统锁定移动方向：只允许沿 水平 (X轴)、垂直 (Y轴) 或 45度角 移动。

价值：用户先把第一个放在合适位置，按住 Shift 拖拽第二个，就能保证它们绝对在一条直线上。

开发难度：极低。

3. 多选与批量对齐工具栏 (Alignment Toolbar)
   如果手抖怎么都拖不准，那就让代码来“事后修正”。

交互逻辑：

框选/多选：允许用户按住 Ctrl 点击多个圆圈，或者拉框选中一组圆圈。

工具栏按钮：选中后，顶部出现一组按钮：

[ |← ] 左对齐

[ →| ] 右对齐

[ — ] 顶端对齐 / 底端对齐

[ = ] 水平分布 (Distribute Horizontally) —— 这个对战锤最重要，能让一排兵间隔完全一致。

开发难度：低。纯数学计算，把选中的数组坐标改一下就行。

4. 键盘微调 (Nudge)
   有时候鼠标太灵敏，很难微调 1mm 的距离。

交互逻辑：

选中一个圆圈。

按键盘 上下左右方向键。

每按一次，移动 0.1mm 或 1px。

按住 Shift + 方向键，移动 1mm 或 10px。

价值：这是专门解决“逼死强迫症”的功能，特别是当两个圆圈变红（冲突）时，用键盘敲两下就能刚好变绿。

5. 幽灵距离提示 (Gap Indicators)
   战锤玩家很在意“底座接触 (Base-to-Base)”或者“保持 1 英寸凝聚距离”。

交互逻辑：

当拖拽圆圈 A 靠近圆圈 B 时。

在两圆之间显示一个数字标签，显示 当前间距 (mm)。

如果间距接近 0（紧贴），显示“接触 (Touch)”。

价值：不仅仅是对齐，更是为了符合游戏规则。

综合建议方案
如果资源有限，我建议按照以下顺序实现：

MVP 阶段 (必须有)：

Shift 键锁定轴向：实现最简单的直线排列。

方向键微调：解决鼠标手抖问题。

体验升级阶段 (强烈推荐)：

智能辅助线 (Smart Guides)：只做圆心对齐即可。这是让工具显得“专业”的关键。

锦上添花阶段：

批量对齐按钮。
