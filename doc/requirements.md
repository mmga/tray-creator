# 战锤移动托盘参数化建模 Web 应用 — 需求文档

> 文档创建日期：2026-02-12

## 1. 项目概述

开发一个基于 Web 的参数化 3D 建模工具，用于生成**战锤微缩模型移动托盘（Movement Tray）**。用户通过调整参数实时预览 3D 模型，并可导出为 STL 文件用于 3D 打印。

## 2. 技术栈

| 层面     | 技术                                                  | 版本要求   |
| -------- | ----------------------------------------------------- | ---------- |
| 前端框架 | Next.js (App Router)                                  | 最新稳定版 |
| UI 组件  | shadcn/ui                                             | 最新       |
| 样式     | Tailwind CSS                                          | v4         |
| 3D 建模  | `@jscad/modeling`                                     | v2.x       |
| STL 导出 | `@jscad/stl-serializer`                               | v2.x       |
| 3D 渲染  | Three.js (`@react-three/fiber` + `@react-three/drei`) | 最新       |

## 3. 功能需求

### 3.1 托盘模型结构

移动托盘由以下部分组成：

```
┌─────────────────────────────┐
│  ┌───┐  ┌───┐  ┌───┐       │
│  │ ○ │  │ ○ │  │ ○ │  ...  │  ← 圆形凹槽（放置底座）
│  └───┘  └───┘  └───┘       │
│  ┌───┐  ┌───┐  ┌───┐       │
│  │ ○ │  │ ○ │  │ ○ │  ...  │  ← 行
│  └───┘  └───┘  └───┘       │
│         ...                 │
│        底板 + 边框           │
└─────────────────────────────┘
```

- **底板**：承载所有凹槽的矩形平面
- **边框**：底板四周的围墙，带**圆角**处理
- **凹槽**：圆形，按行列网格排布，用于放置微缩模型底座

### 3.2 参数列表

> **配置原则**：所有参数（包括默认值、公差、范围限制等）均集中在配置文件中管理，不硬编码在业务逻辑中。

| 参数名                   | 说明               | 单位 | 默认值       | 备注                |
| ------------------------ | ------------------ | ---- | ------------ | ------------------- |
| 列数 (columns)           | 每行凹槽数量       | 个   | 1            | 整数，≥1            |
| 行数 (rows)              | 凹槽行数           | 个   | 1            | 整数，≥1            |
| 凹槽直径 (holeDiameter)  | 圆形凹槽的直径     | mm   | 32           | 支持预设和自定义    |
| 边缘间距 (spacing)       | 凹槽边缘之间的距离 | mm   | 配置文件定义 | ≥0                  |
| 边框宽度 (wallWidth)     | 外围边框厚度       | mm   | 配置文件定义 |                     |
| 边框高度 (wallHeight)    | 外围边框高度       | mm   | 配置文件定义 |                     |
| 底板厚度 (baseThickness) | 底板高度           | mm   | 配置文件定义 |                     |
| 凹槽深度 (holeDepth)     | 凹槽下凹深度       | mm   | 配置文件定义 | V1 固定值，后续可调 |
| 边框圆角 (cornerRadius)  | 外围边框的圆角半径 | mm   | 配置文件定义 |                     |

### 3.3 预设底座尺寸

内置战锤常见底座直径预设，用户可一键选择：

| 预设名称 | 直径 (mm) | 适用模型           |
| -------- | --------- | ------------------ |
| 小型步兵 | 25        | 大部分步兵         |
| 中型步兵 | 28.5      | 部分新步兵         |
| 标准步兵 | 32        | AoS / 40K 标准步兵 |
| 大型     | 40        | 精英步兵、小型怪物 |
| 超大型   | 50        | 英雄、较大怪物     |
| 巨型     | 60        | 巨型模型           |

> 凹槽直径 = 底座直径 + 适当公差（如 +0.5mm），便于放入和取出

### 3.4 3D 预览

- 实时渲染当前参数对应的 3D 模型
- 支持鼠标/触摸交互：旋转、缩放、平移
- 适当的光照和材质效果

### 3.5 STL 导出

- 点击按钮将当前模型导出为 **二进制 STL** 文件并下载
- 文件命名包含关键参数（如 `tray_3x5_32mm.stl`）

## 5. 后续扩展（V2+）

以下功能不在 V1 范围内，但设计时需预留扩展空间：

- **阶梯式托盘**：后排逐行递增高度，便于展示和识别
- **方形/椭圆形凹槽**：支持战锤骑兵底座等异形底座
- **混合布局**：同一托盘内不同尺寸的凹槽
- **凹槽深度可调**
- **托盘尺寸约束**：适配特定收纳箱
- **铭文浮雕**：在托盘边框刻字
- **参数方案保存/加载**

## 6. 非功能需求

- **性能**：参数变化后 3D 预览响应时间 < 500ms（10×10 以下规格）
- **兼容性**：支持现代浏览器（Chrome、Firefox、Safari、Edge）
- **响应式**：桌面端优先布局，窄屏下可浏览、核心流程可达
