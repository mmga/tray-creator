# 自定义阶梯模式 2D 性能测量指南

> 日期：2026-04-07
> 适用分支：`codex/stepped-2d-performance`
> 说明：本文件记录测量入口、样本定义和结果模板；当前未附带浏览器实测数值

## 1. 已落地的测量入口

项目里现在已经有一套可重复使用的 stepped 2D 性能测量入口：

- 访问页面时带上 `?perf=1`，右下角状态栏会显示 `MOVE / COLL / OUTL` 三项耗时。
- 如果要关闭性能面板，改成 `?perf=0` 即可。
- stepped 左侧面板会出现“性能测量”区，里面有 `20 / 50 / 100` 槽位压力样本和“清空采样”按钮。
- 加载任意压力样本时，现有采样会自动清零，避免不同样本之间互相污染。

对应代码入口：

- `src/lib/perf.ts`
- `src/components/canvas/CanvasStatusBar.tsx`
- `src/components/SteppedPanel.tsx`
- `src/lib/stepped-perf-fixtures.ts`

## 2. 当前采样项

右下角状态栏中的三项指标含义如下：

- `MOVE`：`pointermove` 热路径总耗时，最接近交互跟手性的体感指标。
- `COLL`：画布碰撞分析耗时，对应 `LayoutCanvas` 中的碰撞检测与连接线数据准备。
- `OUTL`：stepped 分组轮廓预览耗时，对应 `useSteppedLayout` 中的轮廓生成链路。

状态栏显示格式为：

- `last`：最近一次采样耗时
- `avg`：本轮样本加载以来的平均耗时
- `max`：本轮样本加载以来的峰值耗时

## 3. 压力样本定义

三套样本都使用 4 个分组，高度分别为 `8 / 12 / 16 / 20 mm`，并且会把凹槽交错分配到不同组里，用来同时压测：

- 高频拖拽
- 碰撞候选对筛选
- stepped 轮廓上下文叠加

### 3.1 20 槽位样本

- 托盘尺寸：`240 x 196 mm`
- 排列：`5 x 4`
- 间距参数：`5 mm`
- 平滑半径：`64 mm`
- 凹槽尺寸循环：`25 / 28.5 / 32 / 25`

用途：

- 作为轻负载基线，确认交互是否已经接近无感卡顿。

### 3.2 50 槽位样本

- 托盘尺寸：`248 x 168 mm`
- 排列：`10 x 5`
- 间距参数：`4 mm`
- 平滑半径：`56 mm`
- 凹槽尺寸循环：`25 / 28.5 / 25 / 32`

用途：

- 作为日常高密度编辑样本，重点观察 `MOVE avg` 和 `COLL max`。

### 3.3 100 槽位样本

- 托盘尺寸：`250 x 250 mm`
- 排列：`10 x 10`
- 间距参数：`3 mm`
- 平滑半径：`48 mm`
- 凹槽尺寸循环：`25 / 25 / 28.5 / 25`

用途：

- 作为极限压力样本，重点看拖拽时是否出现明显输入延迟，以及 `COLL / OUTL max` 是否失控。

## 4. 建议测量流程

每轮优化后建议按下面流程复测一次：

1. 打开 stepped 模式，并访问带 `?perf=1` 的页面。
2. 在左侧“性能测量”区依次加载 `20 / 50 / 100` 样本。
3. 每个样本加载后，先等待 1 到 2 秒，让非交互态采样稳定。
4. 在 2D 画布中央连续拖拽 3 到 5 秒，优先做单选拖拽。
5. 再框选一批中央凹槽，连续拖拽 3 到 5 秒，记录多选结果。
6. 观察右下角 `MOVE / COLL / OUTL` 的 `avg` 和 `max`，记录到下表。
7. 切到下一个样本前，点击“清空采样”或直接重新加载样本。

## 6. 建议判读方式

优先关注顺序建议如下：

1. `MOVE avg`
   这是最直接反映跟手性的指标。
2. `MOVE max`
   这个值如果经常明显飙高，用户就会感觉到偶发顿挫。
3. `COLL max`
   这个值高时，通常说明高密度样本下碰撞候选对仍然过多。
4. `OUTL avg`
   这个值持续偏高时，说明 stepped 专属轮廓预览仍然占着比较多的主线程预算。
