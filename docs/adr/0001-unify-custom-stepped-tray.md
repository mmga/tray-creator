# 统一自定义阶梯底座模式

自定义阶梯底座与 CAD 阶梯底座共享同一套手动槽位和高度分组语义，原有差异主要来自内部建模算法以及椭圆、分件装配等附加能力，不足以构成两个用户可理解的产品模式。系统统一保留一个用户入口“自定义阶梯底座”、一个运行时及新持久化身份 `stepped`，并以按高度带草图挤出的 **CAD Stepped Construction** 作为唯一权威建模后端；椭圆属于常规槽位能力，分件与装配作为默认关闭的高级能力存在。

旧 `stepped` 与 `stepped-cad` 参数文件和草稿均继续可读，并在载入时归一到 `stepped`：旧 `stepped-cad` 在缺少显式总开关时默认开启分件与装配，旧 `stepped` 默认关闭。迁移兼容保证槽位尺寸与位置、分组高度、凹槽深度、预期外轮廓和可打印性，不保证 STL 字节、面片、精确体积或内部拓扑一致。完成历史样本的关键尺寸与可制造性验证后，删除旧按组实体建模器，不保留运行时回退；回滚依赖版本控制和发布边界，而不是继续维护双后端。

删除旧后端前还必须通过非拆件性能门槛：在同一设备上使用 20、50、100 槽压力样本和至少两个真实历史普通阶梯文件对比，两套后端的中位生成时间差不得超过 25%，任一样本恶化超过 50% 即阻止删除并要求先优化 CAD 路径。分件装配性能单独记录基线，不与完整模型共用门槛；旧后端只在迁移开发期间用于基准对照。

## 否决的方案

- 保留两个顶级模式：会迫使用户选择内部算法，并持续复制导入、草稿、面板和测试链路。
- 将 `stepped-cad` 保留为新文件身份：会让同一产品语义继续拥有两个协议身份，并保留历史导入歧义。
- 长期保留旧后端作为隐藏回退：会形成两套几何真相，使后续结构能力必须双实现、双验证。
