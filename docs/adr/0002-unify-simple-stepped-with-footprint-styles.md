# 以底座轮廓样式合并简易阶梯建模能力

自定义底座与自定义阶梯底座均增加模型级 **Baseplate Footprint Style**，在矩形包络与贴合轮廓之间选择。该选择描述整件模型的底座构造规则，而不是单纯的边缘外观，也不允许每个高度组独立选择。自定义与阶梯的贴合轮廓必须共用同一套 **Contoured Footprint Construction**，使二维预览、三维生成、尺寸、实体数量和底孔边缘校验消费同一个轮廓结果。

矩形阶梯的最低高度层是包围全部槽位的连续矩形；更高的每个高度带由仍延伸到该高度的分组矩形包络并集构成。包络在托盘坐标系中保持轴对齐，并包含旋转后的最终槽位几何和边界间距。只有最低连续层应用模型级圆角，更高分组保持直角。自动或固定尺寸只决定最低层，不能把固定尺寸传播到更高高度带。

系统保留原简易阶梯的模型生成能力，但不保留行管理、自动行布局和统一高度步进工作流。`simple-stepped` 仅作为历史读取别名：非空行按原顺序转换为高度组，行内坐标投影为全局槽位坐标，行间距固化在位置中；空行不生成组且不消耗高度步进。转换结果使用固定尺寸的矩形阶梯，新保存、草稿和导出只写 `stepped`。转换必须保留关键尺寸、槽位最终几何、最低层圆角、各高度顶面、凹槽深度、底孔结构、可打印实体数量和可制造性；关键线性误差不超过 0.1mm，体积差不超过 1%，不承诺 STL 字节、面片或布尔拓扑一致。

矩形与贴合轮廓都支持完整分件装配。切换样式立即更新二维轮廓并使整件和分件预览失效，但保留另一种样式的休眠参数。自定义贴合轮廓休眠固定尺寸、圆角和侧面斜角；矩形阶梯休眠平滑与断开设置。贴合轮廓允许产生多个独立可打印实体，界面必须显示实体数量并给出提示，但不自动连接或阻止生成。槽间距与边界间距是独立概念；边界间距默认跟随槽间距，也可单独配置。

删除旧简易阶梯后端前，使用 10、30、50 槽样本和至少两个历史文件进行等价性与性能验证，不测试不符合实际制造规模的 100 槽场景。每个样本预热后测量三次并取中位数：全部样本比率的中位数不得超过 1.25，任一样本不得超过 1.5。未通过时先优化矩形高度带构造；通过后删除旧运行时、工作区、建模后端和临时对照基准，不保留隐藏回退。

## 后果

- 用户只需理解两个现行编辑工作流及其底座轮廓样式，不再为历史简易阶梯选择独立模式。
- 阶梯矩形样式仍可使用全局布局优化，但评分必须基于真实高度带面积、包络空白和材料体积，不能只看所有槽位的总外接框。
- 自定义贴合轮廓暂不支持侧面斜角；以后若增加，必须先定义凹轮廓、窄连接和多实体情况下的有效性规则。
- 历史兼容集中在读取转换边界，现行运行时与持久化协议不承担双模式维护成本。

## 否决的方案

- 长期保留简易阶梯顶级模式：会继续复制参数面板、草稿、预览、导出和建模链路。
- 只给现有阶梯分组加矩形边缘：无法生成原简易阶梯连续最低层，模型语义不等价。
- 允许每组混用矩形和贴合轮廓：会显著放大高度带、分件接触面和布局优化的组合复杂度。
- 强制连接贴合轮廓的多个实体：会改变用户布局意图，并可能产生不可控的细桥和制造风险。
- 永久保留旧后端作为回退：会形成两套几何真相，使后续能力必须重复实现和验证。
