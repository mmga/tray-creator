# 阶梯收纳展示台使用独立模式与固定托盘接口

新增独立 `storage-stepped` 模式（阶梯收纳展示台），不扩展现有自定义阶梯底座的参数语义。新模式以一个三级空心主体加三块可互换整宽托盘表达产品；主体负责承托、定位与收纳，托盘负责模型槽位与可选底孔。既有 `stepped`（自定义阶梯底座）及其历史文件继续保持原语义，不自动转换为收纳主体。

主体与托盘共同消费一份接口尺寸推导结果：主体宽度、单阶深度、阶数、托盘总厚度、下部壁厚、上沿厚度、指扣直径、主体底板厚度、单边装配间隙和底部倒角退让。主体开口、托盘外形、二维编辑边界、装配位置和校验均从这份结果派生，避免接口两侧尺寸漂移。接口实际参数与接口版本随参数快照保存；参数偏离默认值时只能标记为“不能与默认接口无条件互换”，不能仍宣称兼容。

托盘总厚度固定为 6 mm。槽底厚度由 `6 − 槽深` 推导，底孔深度、剩余底壁与侧壁共同校验；不满足时阻断生成或导出，禁止自动加厚托盘或修改安装接口。现有平面托盘的“底板厚度 + 槽深 = 总高”规则不适用于本模式。

主体先由阶梯侧面轮廓沿宽度挤出连续实体，再切出三个下仓、三个上部安装口和六个局部指扣，避免三个独立盒体以共面接触拼接。指扣切削限制在对应侧壁厚度范围内，不贯穿主体内部，也不切削托盘。三块托盘各自身份稳定，保留独立打印坐标与装配变换；视图中的提起位移、选中与隐藏状态不进入产品参数与导出几何。

## 后果

- 新模式必须同时接入类型、模式目录、Workspace、Viewport、Worker、参数导入导出、归一化、草稿与多文件导出；任何遗漏由类型检查发现。
- 主体与各托盘按各自几何指纹缓存：高度变化只重建主体与装配位置，某阶槽位变化只重建该托盘，接口变化使全部相关零件失效。
- 预设名称只用于界面说明，几何重建以实际槽位快照、底孔参数和接口实际尺寸为准；未取得实测数据的 32 mm 十人布局必须标注为推导布局。
- 自定义托盘布局只能通过显式导入并报告平移与冲突；超界或间距不足时报告冲突，不缩放、不裁剪。
- 后续的半宽托盘、更多模数或阶数、抽屉、铰链、卡扣、钢板嵌槽、主体拆分打印与 STEP 需要新的接口版本与打样记录，不在此模式首版范围内承诺。

## 否决的方案

- 复用 `stepped` 模式的分组高度参数：会把“每组槽位自定高度”的语义混入固定三级主体，无法保证托盘互换。
- 让槽底厚度跟随底孔自动增加托盘总厚度：破坏 6 mm 接口与齐平装配，且会悄悄改变承托尺寸。
- 用三块独立盒体布尔并集构造主体：共面接触会留下内部面与拓扑问题，截面和装配校验不可信。
- 以预设名称作为重建几何的唯一依据：预设修正或删除后旧文件会漂移，无法复现历史模型。
- 把旧阶梯参数文件整体转换为收纳主体：两者产品语义不同，转换会造成尺寸和仓室行为误解。
