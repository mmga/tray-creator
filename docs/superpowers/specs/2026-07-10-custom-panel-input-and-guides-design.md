# 自定义面板输入与固定托盘提示优化设计

## 目标

修复自定义模式固定托盘尺寸输入被实时范围校验打断的问题；让固定托盘可用区域的虚线提示与既有托盘提示线保持一致的轻量风格；调整圆形凹槽区域的自定义直径入口布局。

## 尺寸输入

`ParamSlider` 保持滑块的实时、受控更新行为，但数字输入框改为拥有独立的临时文本值：

1. 用户键入时只更新输入框文本，不调用外部 `onChange`，允许暂时为空、未完成的小数或低于最小值的中间状态。
2. 用户按 Enter 或输入框失焦时，解析文本并校验当前有效范围。
3. 有效数值调用 `onChange` 提交；无效、空或越界数值恢复到最近的有效参数值。
4. 外部参数变更会在输入框未聚焦时同步显示值；滑块仍沿用现有实时更新和方向键防误触逻辑。

该行为属于通用参数控件，因此固定托盘长度、宽度及其他使用 `ParamSlider` 的字段均获得一致的可编辑性。

## 固定托盘可用区域提示

画布中的固定托盘可用区域继续使用金色表示正常、红色表示存在凹槽越界；仅将其线宽、虚线间隔与既有托盘外框提示线统一为更细、更舒缓的视觉密度。它仍是不可交互的状态提示，不改变越界逻辑、生成或导出行为。

## 圆形凹槽入口

“添加凹槽”中的圆形分组改为：

1. 先展示圆形预设按钮。
2. 在分组底部展示一行自定义直径控件：标签、数值输入框、添加按钮同行。
3. 保持现有可访问标签、直径校验和添加回调，不改变椭圆入口或凹槽定义快照。

## 测试

- `ParamSlider`：从有效大尺寸逐字符输入新值时不回弹；按 Enter 或失焦后一次提交；无效值恢复。
- 画布覆盖层：固定可用区域使用与托盘外框一致的线宽和虚线节奏，同时保留越界颜色。
- `CustomPanel`：圆形预设在前，自定义直径控件位于其后，且标签、输入、按钮为单行结构。

## 非目标

- 不更改参数上下限、参数导入导出、草稿格式或价格计算。
- 不更改固定托盘越界的规则、随机排版、生成或导出是否可用。
