# 堆叠盒体倒角导向装配开发设计

> 日期：2026-09-08
> 状态：已实施；2026-09-08 增加 2 mm 墙厚、开口下沿打印过渡斜面，并修复顶部边界退化面
> 适用范围：现有 `grid`、矩形 `custom` 的堆叠盒体与平板盖
> 替代范围：替代原“底部环形凸缘 + 顶部环形凹槽”的堆叠定位截面，不改变盒体模式、槽位、预览、导出和草稿的既有产品范围

## 1. 背景与问题

当前 `src/lib/stackable-box-model.ts` 的装配结构由窄环形凸缘、顶部环形凹槽、底部承重肩浅凹区和额外承接斜坡共同组成。该实现的核心仍是“凸缘插槽配合”，几何层级多，局部共面和近共面关系复杂，而且没有准确表达已经确认的装配关系。

目标结构不是窄凸缘插入窄凹槽，而是：

- 上层盒子底部形成一个连续的、向下逐渐内收的外倒角导向段；
- 下层盒子开口顶部形成一个连续的、向上逐渐外扩的内倒角导向段；
- 主墙到开口加宽区之间使用连续斜面过渡，不保留向下悬空的水平台阶；
- 盒底导向肩只保留内侧有效水平承重面，外侧悬空段改为连续打印斜面；
- 放置有横向偏差时，两组斜面先接触并引导上层盒子居中；
- 完全落下后，上层盒子底部外围水平肩面与下层盒子顶部水平沿接触承重；
- 对齐状态下，两组倒角之间保留单边打印间隙，不允许倒角顶死或承担主要竖向载荷。

因此，本次开发应直接替换装配截面，不在现有凸缘、凹槽和承接斜坡上继续补丁式调整。

## 2. 目标与非目标

### 2.1 目标

1. 用两段互相平行、方向对应的 45° 倒角完成粗定位导向。
2. 用明确的上下水平面完成竖向承重，装配高度不受倒角尺寸误差控制。
3. 保留每侧可配置的 XY 配合间隙，使 FDM 打印件不易卡死。
4. 保持相同外部长宽的盒体可互相堆叠，不同高度和内部槽位不影响配对。
5. 盖子复用同一底部导向截面，盖到盒口时遵守相同的间隙与承重规则。
6. 删除旧截面中不再需要的窄凸缘、环形凹槽和额外斜坡接收腔，降低 CSG 复杂度。

### 2.2 非目标

- 不改变堆叠盒体支持的 Mode 范围。
- 不新增卡扣、摩擦锁紧、密封、防水或抗倾覆锁止结构。
- 不保证不同外部长宽盒体之间混合堆叠。
- 不让倒角成为精密贴合面或主要承重面。
- 不重做槽位布局、盒体尺寸校验、Worker 请求或双 STL 导出协议。
- 不在本次设计中增加新的用户可调参数；先复用现有 `xyFitClearance`。

## 3. 权威装配截面

以下定义以盒体外侧面为基准，以“距外侧面的内缩量”描述截面，避免把内外轮廓尺寸混淆。

设：

- `R`：顶部结构边总宽，沿用 `topRimWidth`；
- `W`：主墙厚，固定为 `bodyWallThickness`；
- `B`：盒底保留的有效水平承重宽度，固定为 `minLoadBearingWidth`；
- `A_b`：盒底承重面外侧过渡斜面角度；
- `T_b`：盒底承重面外侧过渡斜面高度；
- `T`：开口下沿打印过渡斜面高度；
- `G`：倒角导向高度；
- `C`：每侧 XY 配合间隙，沿用 `xyFitClearance`；
- `H`：下层盒体外高；
- `z`：上层盒体底部局部高度，`0 ≤ z ≤ G`。

首版固定值建议：

| 项目 | 建议值 | 说明 |
| --- | ---: | --- |
| 主体墙厚 `W` | `2.0 mm` | FDM 打印的固定主墙厚度 |
| 顶部结构边总宽 `R` | `6.0 mm` | 沿用现有规格，给承重面与导向倒角留出空间 |
| 开口下沿过渡高度 `T` | `4.0 mm` | `R - W`，使内轮廓在 45° 下连续过渡 |
| 开口下沿过渡角度 | `45°` | 每层逐步向内收，避免向下悬空台阶 |
| 盒底有效水平承重宽度 `B` | `2.0 mm` | 与下层顶部承重环重叠后的最小有效承重宽度 |
| 盒底外侧过渡角度 `A_b` | `45°` | 仅替代水平承重面外侧的悬空段 |
| 盒底外侧过渡高度 `T_b` | `2.0 mm` | 水平外伸 `R-G-B=2.0 mm` 在 45° 下的垂直高度 |
| 倒角导向高度 `G` | `2.0 mm` | 45° 时同时提供 `2.0 mm` 水平捕获范围 |
| 倒角角度 | `45°` | 建模简单、FDM 友好、X/Z 投影关系直接 |
| 默认单边间隙 `C` | `0.4 mm` | 比原 `0.25 mm` 更符合粗定位而非精密插槽；范围建议 `0.25–0.60 mm` |
| 顶部水平承重边宽 | `R - G = 4.0 mm` | 下层盒口最上表面的连续水平承重宽度 |
| 上层底部水平肩宽 | `R - G + C = 4.4 mm` | 默认值；比下层承重边多一个间隙量，保证完整覆盖承重面 |
| 堆叠侵入深度 | `G = 2.0 mm` | 上层盒底导向段进入下层开口的深度 |

必须满足以下结构约束：

```text
0 < G < R
C > 0
R - G >= 2.0 mm
G <= trayTopZ
T = R - W = 4.0 mm
R - G - B = 2.0 mm
T_b = (R - G - B) / tan(A_b) = 2.0 mm
H >= max(trayTopZ, G + T_b) + T + G
```

`G <= trayTopZ` 保证底部导向段不会高于盒底实体；若现有业务允许更薄的 `trayTopZ`，则动态使用 `min(G, trayTopZ)` 会破坏跨盒兼容性，因此应阻止生成并提示底部厚度不足，而不是静默缩短导向段。

`T` 把主墙内轮廓从 `W=2.0 mm` 连续过渡到顶部加宽内轮廓 `R=6.0 mm`。首版 `T=4.0 mm`、角度为 `45°`，因此每 1 mm 高度只增加 1 mm 的内缩量，适合 FDM 逐层打印。顶部内倒角仍独立占用 `G=2.0 mm`，不能通过缩短过渡斜面或倒角来绕过最小外高约束。

盒底导向段在 `Z=G` 处保留从内缩 `R-G+C` 到内缩 `R-G-B` 的水平承重面，宽度为 `B+C`；下层盒口顶部水平承重环从外轮廓延伸到内缩 `R-G`，两者相交后的有效承重宽度为 `B`。从内缩 `R-G-B` 起，外侧不再生成悬空水平面，而是以 `A_b=45°` 斜面延伸到完整外轮廓。默认水平外伸 `2.0 mm`，斜面高度 `T_b=2.0 mm`。

### 3.1 下层盒口加宽下沿的打印过渡斜面

主墙的内轮廓在 `Z = H - G - T` 处内缩 `W`，向上连续过渡到 `Z = H - G` 处内缩 `R`：

```text
lowerTransitionInset(t) = W + (R - W) × t
t = (Z - (H - G - T)) / T, 0 ≤ t ≤ 1
```

该斜面替代原先从 `W` 直接跳到 `R` 的水平下沿。因为内轮廓向上每层只向盒内移动约 1 mm，新增材料始终有下层支撑，不需要支撑结构；过渡结束后直接接顶部内倒角的下端。

### 3.2 下层盒口内倒角

下层盒口在倒角底部 `Z = H - G` 的内轮廓内缩量为 `R`；在顶部 `Z = H` 的内轮廓内缩量为 `R - G`。

45° 内倒角从下向上连续外扩：

```text
lowerOpeningInset(t) = R - G × t
t = (Z - (H - G)) / G, 0 ≤ t ≤ 1
```

下层盒体的顶面从外轮廓延伸到 `R - G` 处，形成宽度为 `R - G` 的连续水平承重环。倒角下方不再使用悬空水平台阶，而是连接到上一节的打印过渡斜面。

### 3.3 上层盒底外倒角

上层盒底导向段在最低点 `z = 0` 的外轮廓内缩量为 `R + C`；在肩面高度 `z = G` 的外轮廓内缩量为 `R - G + C`。

45° 外倒角从下向上连续外扩：

```text
upperInsertInset(t) = R + C - G × t
t = z / G, 0 ≤ t ≤ 1
```

上层盒子的导向配合仍在 `z=0..G` 完成。`z=G` 处只保留内侧水平承重面；外侧从内缩 `R-G-B` 向完整外轮廓连续上升，避免原先从内缩 `R-G+C` 直接跳到外轮廓而形成的悬空水平面。上层承重面仍位于全局 `Z=H`，因此堆叠平移仍为 `H-G`。

### 3.4 对齐后的间隙与承重

上层盒子完全落下时整体平移到：

```text
upperTranslationZ = H - G
```

此时上下倒角在直边区域、任意相同全局高度的内缩量差恒为：

```text
upperInsertInset - lowerOpeningInset = C
```

即直边每侧始终保留 `C` 的水平间隙。上层肩面位于全局 `Z = H`，与下层顶面共面接触。导向段最低点位于 `H - G`，不接触下层盒内实体。

圆角区域不能仅凭宽、深内缩量推导实际最短间隙。特别是内缩量达到外圆角半径后，`max(outerCornerRadius - inset, 0)` 会把圆角钳为零，两个截面的角部形态不再能用“半径相差 `C`”证明处处等距。实现时应把每一高度的上层导向轮廓定义为对应下层开口轮廓向内偏移 `C` 的结果；若 JSCAD 二维偏移在圆角退化处不稳定，则允许继续使用解析圆角矩形，但必须用角部探针或距离采样证明最小间隙不小于 `C`。产品合同是“全周不小于 `C`”，不是“圆角区水平距离处处恰好等于 `C`”。

这三项应成为权威装配判据：

1. 水平承重面共面；
2. 直边倒角间隙恒为 `C`，圆角区域全周最小间隙不小于 `C`；
3. 除允许的共面接触数值残差外，上下盒体交集体积为零。

## 4. CAD 构造方案

### 4.1 盒体主体

保留现有主体语义，并将盒底承重肩拆成“有效水平承重 + 外侧打印斜面”：

1. `Z=0..G` 生成原有底部外倒角导向段。
2. `Z=G` 处从内缩 `R-G+C` 到内缩 `R-G-B` 保留水平承重面。
3. 从内缩 `R-G-B` 到完整外轮廓生成 `A_b=45°` 外侧打印斜面，高度为 `T_b`。
4. 斜面顶部以上恢复完整外轮廓；若 `trayTopZ < G+T_b`，只在斜面以上切回主墙内轮廓，不能用实体封死内部空间。
5. 内部托盘顶面以上生成 `W=2.0 mm` 固定主墙环，直到 `H-G-T`。
6. 在 `H-G-T..H-G` 生成从内缩 `W` 到内缩 `R` 的连续 `T=4.0 mm` 打印过渡斜面。
7. 在最后 `G=2.0 mm` 生成顶部内倒角和水平承重环。
8. 内部槽位、零间距岛区和底板孔位仍由现有模式建模器在空白主体上切削。

底部不再先生成完整落地底板再切出悬空肩，而是直接分成：

- `Z = 0..G`：由两个圆角矩形切片放样得到的中央导向实体；
- `Z = G`：导向顶边到斜面起点之间保留水平承重座，实际宽度为 `B+C`；
- `Z = G..G+T_b`：从内缩 `R-G-B` 向完整外轮廓连续上升的外侧打印斜面；
- `Z = G+T_b..trayTopZ`：若仍有剩余底部厚度，再恢复完整外轮廓底板实体；
- 当 `trayTopZ < G+T_b` 时，从 `trayTopZ` 到 `G+T_b` 只保留斜面外壳并切回内壁轮廓，不用实体封死内部空间。

这一构造清楚表达真实截面，也避免旧实现中“浅凹区 + 窄凸缘 + 承接斜坡”的重叠布尔关系。

最终并集几何在精确 `Z = G` 截面同时包含完整外轮廓与导向段顶边。测试导向轮廓时必须取 `G - ε`，测试肩面与完整外轮廓时取 `G` 或 `G + ε`，不能用最终模型在精确边界层的最外顶点反推导向轮廓。

### 4.2 顶部内倒角

顶部开口不再切环形凹槽。过渡斜面和顶部内倒角分别构造，再在相邻边界处保留极小布尔容差：

1. 主墙顶部以下保持普通内轮廓，主墙厚度为 `W=2.0 mm`。
2. 用 `extrudeFromSlices` 生成从 `W` 内缩轮廓到 `R` 内缩轮廓的过渡腔，并从外轮廓实体中执行差集。
3. 在过渡斜面上方生成 `R` 内缩的顶部环体。
4. 再用 `extrudeFromSlices` 生成从 `R` 内缩轮廓到 `R-G` 内缩轮廓的顶部内倒角开口体并执行差集。
5. 顶部内倒角开口体使用精确 `H-G..H` 端点；过度延伸会在 `H-G` 水平边界产生退化 STL 三角面。过渡斜面实体仍可在下端保留极小重叠以连接主墙，但权威尺寸仍使用设计值。

禁止保留：

- `grooveWidth = flangeWidth + 2 × xyFitClearance`；
- 窄环形 `grooveRing`；
- `slopeReceiverRing`；
- `flangeRing`、`flangeStraight`、`flangeChamfer`；
- 额外的 `seatingSlopeRing`。

### 4.3 圆角矩形一致性

下层开口的所有截面必须由同一外轮廓按内缩量派生：

```text
width(inset) = outerWidth - 2 × inset
depth(inset) = outerDepth - 2 × inset
radius(inset) = max(outerCornerRadius - inset, 0)
```

不得分别手写宽、深和圆角公式。建议新增私有辅助函数 `insetRoundedRectangleProfile`，输入外部长宽、外圆角和内缩量，统一返回下层开口轮廓。上层导向轮廓优先由对应下层轮廓再向内偏移 `C` 得到；若使用解析圆角矩形替代偏移运算，则圆角退化后的最小间隙必须由测试锁定，不能只验证直边。

### 4.4 盖子

盖板主体与指甲槽保持不变，但装配侧改为与盒底相同的中央外倒角导向实体：

- STL 打印方向仍是盖板大平面贴床；
- 导向实体位于盖板上方，装配时翻转后进入盒口；
- 盖板与导向实体之间的环形水平面承担盖合载荷；
- 盖子不再生成窄定位凸缘。

盖子在打印坐标中的权威截面为：

```text
zPrint = lidThickness      时，导向轮廓内缩 R - G + C
zPrint = lidThickness + G  时，导向轮廓内缩 R + C
```

即导向结构从盖板表面向上逐渐内收。装配时将盖子翻转并平移，使盖板的水平承重环与盒口顶面共面；翻转后的截面才与盒底“从下向上逐渐外扩”的装配方向一致。不得未经反向便复用盒底的切片顺序。

## 5. 参数与领域模型调整

### 5.1 固定规格重命名

`STACKABLE_BOX_SPECS` 建议调整为：

```ts
{
  bodyWallThickness: 2.0,
  outerCornerRadius: 6.0,
  topRimWidth: 6.0,
  guideChamferHeight: 2.0,
  topTransitionHeight: 4.0,
  topTransitionAngle: 45,
  bottomSeatSlopeAngle: 45,
  guideChamferAngle: 45,
  minLoadBearingWidth: 2.0,
  minWallRise: 2.4,
  // 盖子指甲槽规格保持不变
}
```

删除旧字段：

- `flangeWidth`
- `flangeHeight`
- `grooveDepth`
- `flangeGrooveBottomClearance`
- `locatorRingCenterlineInset`
- `flangeEntryChamfer`

顶部加宽过渡不再使用 `topReinforcementHeight` 表示；改由固定的 `topTransitionHeight` 和 `topTransitionAngle` 表示，避免墙厚变化后把水平台阶误当作可打印结构。

`StackableBoxParams` 继续保留 `xyFitClearance`，其语义从“凸缘与凹槽间隙”改为“底部外倒角与顶部内倒角之间的每侧水平间隙”。字段名和持久化格式无需迁移。

删除或改名现有 `calculateBoxGrooveWidth`。新截面不再存在“槽宽”，继续暴露该函数会让调用方保留错误领域概念；若 UI 或测试需要派生值，应提供 `calculateGuideOpeningInset`、`calculateBottomInsertInset` 等与真实截面对应的纯函数。

### 5.2 默认值与范围

本设计推荐把默认 `xyFitClearance` 从 `0.25 mm` 调整为 `0.4 mm`，范围调整为 `0.25–0.60 mm`。原因是新结构以粗定位和防滑为目标，不依赖紧配合；更大的首版间隙能覆盖常见 FDM 尺寸偏差、象脚和轻微翘曲。

这是默认行为变化，但不是文件格式破坏：

- 历史文件已保存具体数值时继续使用原值；
- 历史文件缺失该字段时使用新默认值；
- 导入归一化记录无需新增结构版本，只需沿用字段补全记录。

### 5.3 派生高度

把所有使用旧 `flangeHeight` 表示堆叠侵入量的地方改为 `guideChamferHeight`：

```text
stackClearHeight = lidClearHeight - guideChamferHeight
```

结果摘要中的“堆叠净高”语义不变，但默认值会因侵入深度从 `1.2 mm` 变为 `2.0 mm` 而变化。

### 6.3 新增阻断语义

`BoxBlockingCode` 增加底部结构不足的专用代码，例如 `bottom-too-thin-for-guide`，中文消息应同时给出当前 `trayTopZ` 和所需 `G`。普通完整槽使用 `baseThickness + holeDepth` 形成底部实体时，权威底部可用厚度仍以传给 `createStackableBoxBody` 的 `trayTopZ` 为准；`basePlateOnly` 使用 `baseThickness`。若 `trayTopZ < G+T_b`，斜面段上方需要先切回主墙内轮廓，外高下限按 `max(trayTopZ, G+T_b) + T + G` 计算。

领域校验负责在生成前阻断 `trayTopZ < G` 以及 `H < max(trayTopZ, G+T_b) + T + G`。`createStackableBoxBody` 作为共享 CAD 边界仍应对非有限值、`trayTopZ < G` 和顶部结构高度不足抛出明确错误，避免绕过 UI 的调用生成不兼容几何。分别覆盖 `trayTopZ = G` 可生成、`trayTopZ = G - ε` 被拒绝，以及 `H = max(trayTopZ, G+T_b) + T + G - ε` 被拒绝的边界测试。

## 7. 测试设计

### 7.1 纯领域测试

1. 默认间隙为 `0.4 mm`，允许范围为 `0.25–0.60 mm`。
2. 主体墙厚固定为 `2.0 mm`，开口下沿过渡斜面为 `4.0 mm × 45°`。
3. `guideChamferHeight < topRimWidth`。
4. `topRimWidth - guideChamferHeight >= minLoadBearingWidth`。
5. 堆叠净高按倒角导向高度扣减。
6. 盒底保留 `2.0 mm` 有效水平承重，外侧斜面为 `45°`，不再有完整 `R-G+C` 宽度的悬空水平肩。
7. 最小外高至少覆盖 `max(trayTopZ, guideChamferHeight + bottomSeatSlopeHeight) + topTransitionHeight + guideChamferHeight`。
8. 底板实体厚度低于导向高度时返回阻断原因。
9. 历史参数中显式的 `xyFitClearance=0.25` 保持不变。

### 7.2 截面几何测试

在远离圆角的直边中部使用小探针体积测试以下位置：

1. 盒底 `z=0` 的最外实体边界位于内缩 `R + C`。
2. 盒底 `z=G-ε` 的导向段最外边界趋近内缩 `R - G + C`。
3. 盒口 `z=H-G` 的开口边界位于内缩 `R`。
4. 盒口 `z=H` 的内侧开口边界位于内缩 `R-G`；不得用整个实体的最外边界判断。
5. 盒底从导向顶边到斜面起点的水平承重座在 `z=G` 连续存在。
6. 盒口顶部水平承重环在 `z=H` 连续存在。
7. 盒底水平承重面保留 `B+C` 宽度，外侧 `R-G-B` 宽度改为 `A_b` 斜面。
8. 开口下沿过渡斜面中部的内轮廓位于 `W` 与 `R` 的线性插值处。
9. 过渡斜面下端不再出现从 `W` 直接跳到 `R` 的水平悬空台阶。
10. 旧窄凸缘所在区域不再出现独立直壁环。
11. 旧环形凹槽底部不再存在水平槽底。
12. 导出的本体 STL 三角面不包含零面积退化面，且 Z 包围盒严格落在 `0..H`。

不应只检查顶点最大值；需要结合 `intersect` 探针验证实体/空腔两侧，否则圆角和三角化变化可能让测试误判。

### 7.3 装配几何测试

1. 同尺寸上下盒以 `H-G` 平移叠放时，交集体积同时满足绝对值 `< 0.05 mm³` 且小于上层盒体体积的 `1e-7`；局部探针不得发现连续干涉区。
2. 上层肩面与下层顶面位于同一高度。
3. 在倒角底部、中部和顶部三个高度，直边单边间隙均为 `C`，圆角区域的最小间隙均不小于 `C`。
4. 上层继续下移一个小量时产生实体交叠，证明水平承重面先阻止下沉。
5. 在小于倒角捕获范围的横向偏移下，至少一侧倒角发生接触趋势；该测试可基于截面距离判据，不必依赖物理仿真。
6. 不同高度但相同外部长宽的盒子保持兼容。
7. 不同外部长宽仍判定为不保证兼容。
8. 对 `C=0.25 / 0.40 / 0.60 mm` 分别执行直边、四角、倒角底部和半径钳零过渡高度的装配检查。
9. 上层额外下移 `ε` 时，交叠必须首先出现在水平承重环，不能先出现在倒角或圆角区。

### 7.4 盖子测试

1. 盖子导向截面与盒底导向截面尺寸一致。
2. 翻转到装配方向后，盖子与盒口无实体交叠。
3. 盖板水平承重面先于倒角接触。
4. STL 打印方向保持大平面贴床，导向外倒角不需要支撑。
5. 两侧指甲槽位置和尺寸不回归。

### 7.5 回归测试

- `grid` 与矩形 `custom` 各生成至少一个盒体、盖子和旁置预览。
- 普通托盘关闭盒体时，包围盒和体积快照不变化。
- 参数导入导出、草稿恢复和结果摘要通过现有测试。
- Worker 仍返回两个独立 STL，并且盒体与盖子来自同一参数快照。
- 对默认尺寸以及最小允许尺寸各执行一次非流形边检查；若项目现有测试工具无法可靠判断，则至少验证正体积、有限包围盒、无退化多边形和 STL 序列化成功。

### 阶段 3：更新领域投影与界面文案

### 阶段 4：全链路回归

完成标准：自动化测试和构建通过，视觉检查确认倒角方向、水平承重面和装配间隙均符合本设计。

## 9. 验收标准

1. 模型中不再存在窄环形定位凸缘和对应环形凹槽。
2. 上层盒底外轮廓从下向上外扩，下层盒口内轮廓从下向上外扩，两者在装配坐标中保持平行。
3. 默认对齐装配时，直边每侧倒角间隙为 `0.4 mm` 且在全倒角高度内不变；圆角区域全周最小间隙不小于 `0.4 mm`。
4. 上层盒体由底部外围水平肩面落在下层顶部水平沿上承重。
5. 对齐装配无可感知实体交叠，倒角底部也不触底。
6. 同外部长宽、不同高度和内部槽位的盒体可互相堆叠。
7. 盖子使用同一导向逻辑且保持免支撑打印方向。
8. 普通托盘及盒体的槽位、底板孔、预览和导出功能无回归。
9. 盒体底部肩面实打后能形成连续、可重复落座的承重面；不允许可见下垂导致倒角先承重或盒体摇晃。

## 10. 风险与回滚边界

### 10.1 主要风险

- 盒底仍保留宽度为 `B+C` 的水平承重面，默认 `2.4 mm`；其外侧 `R-G-B=2.0 mm` 改为 45° 斜面，避免原先约 `4.4 mm` 的整段悬空肩。水平承重面的实际打印平整度仍需实物验证。
- 45° 倒角的理论间隙是水平间隙；实际法向最短距离约为 `C / √2`。默认 `C=0.4 mm` 时约为 `0.28 mm`，仍需用实际打印机验证。
- 开口下沿新增的 `4.0 mm × 45°` 过渡斜面面向盒内，理论上可逐层打印但仍受层高、线宽和内壁冷却影响；若实物出现下垂，应优先增大角度或缩短单层水平外伸，不得恢复悬空水平台阶。
- 外轮廓圆角处若各层轮廓不是由统一内缩规则生成，可能出现角部间隙不一致或 CSG 碎面。
- 新默认侵入深度增加，会降低结果摘要中的堆叠安全净高；这是正确的结构结果，不应通过保留旧公式掩盖。

### 10.2 回滚边界

本次变更应限制在共享规格、共享 CAD 原语、相关文案和测试。Worker 协议、参数字段名、Mode、草稿格式和导出文件结构保持不变。因此若新截面实物验证失败，可以在一个版本边界内回退上述文件，不需要迁移用户草稿或恢复旧 Worker 协议。

## 11. 实物验证建议

在完整盒体打印前，增加一个只包含单侧直边和一个圆角的截面样件：

- 直边长度约 `50 mm`；
- 保留真实 `2.0 mm` 墙厚、`4.0 mm × 45°` 开口下沿过渡斜面、底部外倒角和顶部内倒角；
- 分别测试 `C=0.30 / 0.40 / 0.50 mm`；
- 检查偏心放置能否自动滑正、完全落下时水平面是否贴合、提起时是否卡滞；
- 检查底部肩面悬挑的打印质量和象脚对导向入口的影响。

实物首选值建议保持 `45° × 2.0 mm`、单边 `0.4 mm`。只有在同一打印配置下重复验证后，才把间隙收紧到 `0.3 mm`。
