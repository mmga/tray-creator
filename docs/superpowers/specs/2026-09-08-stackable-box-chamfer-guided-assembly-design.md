# 堆叠盒体互补斜面装配设计

> 日期：2026-09-09
>
> 状态：已按最终截面实施
>
> 适用范围：`grid` 与矩形 `custom` 模式的堆叠盒体及盖子

## 1. 设计结论

盒体采用倒角导向式自堆叠结构，但盒顶最高处不保留水平面：

- 上层盒子的中央底面直接位于打印平台 `Z=0`，同时作为装配承重面；
- 中央底面的外缘以连续 45° 斜面向上、向外扩展到完整外轮廓；
- 下层盒口的最高处只有完整外轮廓边线，不生成环形水平顶面；
- 盒口从最高外边线以 45° 斜面向内、向下过渡到下沉的水平承重座；
- 承重座内侧再以 45° 斜面过渡到 2 mm 主墙，避免加宽结构出现向下悬空台阶；
- 上下互补导向斜面之间保留每侧 XY 打印间隙；
- 完全落下后仅由上层中央底面与下层下沉承重座的 2 mm 有效重叠区承载。

旧版“底部凸缘 + 顶部凹槽”“盒底抬高承重肩”“盒顶水平沿”的截面均不再使用。

## 2. 权威参数

设：

- `H`：盒体外高；
- `W=2.0 mm`：主墙厚；
- `R=6.0 mm`：盒口内侧结构总宽；
- `G=4.0 mm`：互补导向斜面的有效高度及水平行程；
- `B=2.0 mm`：有效水平承重宽度；
- `C`：每侧 XY 配合间隙，默认 `0.4 mm`；
- 导向斜面、盒底外扩斜面和盒口内侧支撑斜面均为 45°。

固定关系：

```text
G = R - B = 4.0 mm
bottomFloorInset = G + C
bottomSlopeHeight = G + C
topSeatZ = H - G
topSeatOuterInset = G
topSeatInnerInset = R + C
topSeatSupportHeight = R + C - W
stackTranslationZ = H - G
effectiveBearingWidth = (R + C) - (G + C) = B
```

默认 `C=0.4 mm` 时：

| 截面量 | 数值 |
| --- | ---: |
| 盒底中央平面外缘内缩 | 4.4 mm |
| 盒底外扩斜面总高 | 4.4 mm |
| 盒口承重座高度 | `H - 4.0 mm` |
| 盒口承重座范围 | 内缩 4.0–6.4 mm |
| 盒口内侧支撑斜面高度 | 4.4 mm |
| 上下盒有效承重重叠 | 2.0 mm |
| 上下导向斜面直边间隙 | 0.4 mm/侧 |

## 3. 截面与装配

### 3.1 上层盒底

盒底最低截面为内缩 `G+C` 的完整中央平面。外轮廓随局部高度 `z` 线性外扩：

```text
upperBottomInset(z) = G + C - z
0 <= z <= G + C
```

因此最低平面可直接贴床打印，斜面上方逐层有材料支撑。盒底不再存在位于空中的向下水平肩面。

### 3.2 下层盒口

下沉承重座位于 `Z=H-G`，外缘内缩 `G`，内缘内缩 `R+C`。盒口接收斜面为：

```text
lowerTopInset(z) = G - z
0 <= z <= G
```

其中 `z` 从承重座向盒顶计算。斜面在 `z=G` 到达完整外轮廓，所以 `Z=H` 处只有边线而没有水平顶面。

承重座内缘到主墙内缘的加宽部分按 45° 连续过渡，高度为 `R+C-W`。该表面是朝上的内腔斜面，不形成向下悬空水平台阶。

### 3.3 配合过程

上层盒从 `Z=H` 开始垂直下降到 `Z=H-G`：

1. 上层底面先进入下层盒口；
2. 两侧 45° 斜面保持平行，并在直边处保留 `C` 间隙；
3. 有横向偏移时，斜面接触产生回中分力；
4. 最终上层中央底面落在下层下沉承重座上；
5. 继续下沉才会在水平承重区产生实体干涉，导向斜面不作为精密承重面。

同外部长宽的盒体可跨高度、跨内部槽位互相堆叠；外部长宽不同的盒体不声明兼容。

### 3.4 盖子

盖子复用盒底的完整装配截面。打印时完整盖板平面贴床，装配斜面从盖板上表面的完整外轮廓以 45° 收至内缩 `G+C` 的中央轮廓；使用时将盖子翻转。因此盖子与盒体底部具有相同的下落路径、斜面间隙和落座高度。

装配斜面总高为 `G+C`，翻转后的完整外轮廓比盒口最高边高 `C`，所以闭合外高为：

```text
closedOuterHeight = H + C + lidThickness
```

盖子短边不设置指甲槽，保持四周边缘连续。

## 4. 建模约束

盒体外包络使用一个连续轮廓序列放样：

```text
Z=0                    内缩 G+C
Z=G+C                  完整外轮廓
Z=H                    完整外轮廓
```

内腔也使用连续轮廓序列，从托盘顶面延伸到主墙，再以 45° 过渡到承重座内缘。顶部接收斜面作为从内缩 `G` 到完整外轮廓的连续开口切除。

不得把底板、主墙、承重座和斜面拆成多个相邻实体后依赖布尔并集消除接缝；分段共面容易在 STL 中留下内部水平三角面或退化面。

最低外高必须同时容纳底部外扩斜面、内部托盘高度、盒口支撑斜面及顶部接收斜面：

```text
wallStartZ = max(trayTopZ, G+C)
minimumOuterHeight = max(
  trayTopZ + minWallRise,
  wallStartZ + (R+C-W) + G
)
```

薄底板不再因 `trayTopZ < G` 被拒绝；内腔起始轮廓应跟随外扩斜面并保持 2 mm 壁厚。

## 5. 验收标准

### 5.1 几何

- 盒底最低点为 `Z=0`，中央承重面可贴床打印；
- 盒底从内缩 `G+C` 连续外扩到完整外轮廓；
- 盒口承重座位于 `H-G`；
- 盒口从承重座外缘连续升至 `Z=H` 的外轮廓边线；
- `Z=H` 不存在具有面积的水平顶面；
- 承重座内侧由连续 45° 斜面支撑；
- 空白盒体 STL 在 `Z>0` 不含法线朝下的水平三角面；
- STL 不含退化三角面，边界高度严格保持 `0..H`。

### 5.2 装配

- 上层盒从未接触位置到最终落座位置的整段垂直路径无实体穿插；
- 最终平移量为 `H-G`；
- 对齐时两组斜面直边间隙为 `C`；
- 最终水平承重有效宽度为 `B=2.0 mm`；
- 上层继续下沉小量时，首先由水平承重面阻止，而不是斜面顶死。
- 盖子翻转后可沿同一路径下落，最终无实体穿插并由水平座承重；
- 盖子四周连续，不含短边指甲槽。

### 5.3 回归

- 网格与矩形自由布局盒体均可生成、预览和导出；
- 普通槽位、仅底板模式和不同盒高均通过几何测试；
- 结果摘要中的堆叠净高按 `outerHeight - baseThickness - G` 计算；
- 完整单元测试、类型检查、代码检查和生产构建通过。

## 6. 实物验证边界

自动化测试能验证数学装配、网格拓扑和明显悬空面，但不能替代实打。合并后应打印一个含直边和圆角的截面样件，确认：

- 当前材料、层高和挤出设置下，`C=0.4 mm` 不会卡死；
- 2 mm 承重座没有明显翘曲或缺料；
- 圆角区不会先于直边顶住；
- 多层堆叠后无明显摇晃或累计偏斜。
