# 网格零间距孤岛墙体去除设计

## 目标

网格模式中，当实际生效的 X、Y 凹槽间距同时严格等于 `0` 时，删除每组相邻 `2 × 2` 凹槽围成的上层孤岛墙体。底板、外墙与凹槽配合尺寸保持不变。

## 规则

- 统一间距和独立 X/Y 间距使用同一组生效值判断；任一轴大于 `0` 都不触发。
- 仅处理至少两行、两列且不是“仅内嵌孔底板”的网格。
- 删除范围从底板顶面延伸到托盘顶面，不切穿底板。
- 规则按孤岛几何生效，不绑定圆形预设；矩形槽在零间距下本已重叠，结果不变。
- 更大网格删除全部 `(rows - 1) × (columns - 1)` 个内部孤岛。
- 二维图、三维预览和 STL 使用一致的触发规则。
- 外尺寸、凹槽数、报价、文件名和参数格式均不改变，也不增加配置项。

## 实现

共享网格数学模块负责唯一触发判定。实体生成使用一个覆盖首尾凹槽中心范围的上层矩形切削体；该区域等价于所有内部网格单元的并集。零间距时，完全包含在该矩形内的非边缘凹槽不再重复参与布尔减法。

二维图用相同范围填充已移除区域，并与凹槽作为同一透明图层合成，避免重叠区域出现错误的深浅差异。

## 验证

- `3 × 3` 网格的四个孤岛位置均无上层实体，中央底板仍存在。
- 独立间距仅一轴为 0 时保留墙体。
- 二维图仅在完整触发条件下显示孤岛切除区域。
- 既有网格模型和二维图测试继续通过。
- `30 × 30`、无底板孔的零间距压力样例可在约 6 秒内完成；底板孔仍按全部槽位生成。
