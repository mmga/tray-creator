## 1. 目标、范围与完成定义

新增独立模式“阶梯收纳展示台”，运行时标识建议为 `storage-stepped`。生成一个具有三个独立收纳仓的阶梯主体和三个可互换的整宽托盘。托盘用于小队展示、移动和更换，取出托盘后可使用下方收纳仓。

首版包含：两种主体高度、五种托盘预设、自定义槽位、可选底孔、二维编辑、多零件装配与提起预览、单件及全部 STL 导出、JSON、草稿、撤销重做和已有托盘布局显式导入。

后续范围：其他宽深模数、可变阶数、半宽托盘、抽屉、铰链、卡扣、钢板嵌槽、主体拆分打印、STEP。首版界面不能将这些能力显示为已支持。

软件交付要求阶段 1—5 全部通过，阶段 6 完成软件回归与切片记录。产品装配及承重确认另以阶段 6 实物记录为准；缺少样件或负载数据时应明确标记“软件完成，实物待验证”。

## 3. 几何契约与校验基准

单位统一为 mm。主体坐标建议为 X 左右、Y 从前向后、Z 向上；底面 Z=0，第一阶位于前方。编辑坐标与预览中心坐标的转换只在明确边界执行一次。

设 W=240、D=80、N=3、T=6、下壁 t=4、上沿 r=2、间隙 c=0.3、底板 b=2.4、倒角水平退让 q=0.4。第 i 阶从 0 开始：

```text
H(i) = 首阶高度 + 40 × i
模块范围：Y ∈ [iD, (i+1)D]
下仓范围：X ∈ [t, W−t]，Y ∈ [iD+t, (i+1)D−t]
下仓高度：Z ∈ [b, H(i)−T]
安装口范围：X ∈ [r, W−r]，Y ∈ [iD+r, (i+1)D−r]
安装口高度：Z ∈ [H(i)−T, H(i)]，顶部切削增加微小余量
托盘尺寸：(W−2r−2c) × (D−2r−2c) × T
装配时托盘底高：H(i)−T
```

默认下仓为 232×72，安装口为 236×76，托盘为 235.4×75.4×6。相邻下仓在双方仓腔重叠高度区间的隔墙厚度为 8 mm。不得把隔墙改为 4 mm 后仍宣称接口和仓室尺寸完全相同。

承托台阶宽 2 mm；居中时托盘投影覆盖宽 1.7 mm，扣除倒角后的平底接触宽为 1.3 mm；在侧向间隙极限处，对侧约为 1.0 mm。这些是直边段计算值，指扣处承托被局部切断，不能当成周向完整接触或承重结论。

指扣圆心位于每阶侧壁深度中点与台面高度，半径 16 mm，切削轴沿 X，分别贯穿左右侧壁及承托台阶，不切削托盘。最低点为 H(i)−16；托盘下方最大开放高度为 10 mm。指扣形成侧面开口，收纳仓不具备密封或防漏小件承诺。

| 基准 | 标准高度 | 收纳高度 |
| --- | --- | --- |
| 总尺寸 | 240×240×110 | 240×240×120 |
| 仓净高 | 21.6/61.6/101.6 | 31.6/71.6/111.6 |
| 规则仓腔总体积 | 3.0868992 L | 3.5880192 L |

容积按规则长方体计算，界面标为理论值，不等于可用装载容量。实心 CAD 材料体积与切片填充耗材也应分开。

## 5. 阶段 1：参数模型、接口推导与校验

目标：建立主体与托盘共同消费的尺寸来源，先获得可测试的构造数据。

### 开发任务

- [x] S1-01：定义独立 `StorageSteppedParams`，包含接口版本、实际接口参数、主体高度规格和三个托盘配置；不继承普通阶梯高度组参数。
- [x] S1-02：定义稳定的主体及托盘零件身份；托盘槽位复用现有 `FreeSlot` 与尺寸快照。各阶配置按值独立保存，复制使用深拷贝。
- [x] S1-03：建立默认值和纯函数尺寸推导，输出模块边界、仓腔、安装口、托盘外形、装配位置、理论容量和承托宽度。
- [x] S1-04：定义校验结果，区分阻断错误与打样提示。拒绝非有限数、未知接口版本、无效阶配置、重复标识、负间隙、上沿厚度不小于下壁、仓净高不正、倒角破坏承托等输入。
- [x] S1-05：固定托盘总厚度 6 mm，槽底厚由 `6−holeDepth` 推导。底孔不满足剩余底壁时阻断，禁止自动增厚托盘或改变安装接口。
- [x] S1-06：接口打样参数可以配置；任何变动同步重算主体与托盘，显示实际接口尺寸，不能仍标为与默认版本无条件互换。
- [x] S1-07：写参数、派生尺寸、非法边界和配置深拷贝测试；建立两种高度的基准样本。
- [x] S1-08：在 CONTEXT.md 与新 ADR 中记录新模式的领域边界、接口与总厚度语义；既有普通阶梯历史兼容规则保持完整。

建议新增模块：`src/types/storage-stepped.ts`、`src/lib/storage-stepped-config.ts`、`src/lib/storage-stepped-plan.ts`，具体拆分遵循实际职责，避免空壳抽象。

- [x] 两种默认规格的所有派生尺寸符合第 3 节，纯数值计算误差不超过 1e-6 mm。

- [x] 非法导入数据得到带参数位置的可理解错误，不静默改变固定接口。
- [x] 预设名称变化不影响参数重建；未知接口版本明确拒绝。

## 6. 阶段 2：空心主体与平板托盘

目标：先交付能检查装配的主体与平板托盘几何。

- [ ] S2-02：按统一构造计划切出三个下仓及三个上部安装口；切削余量只用于布尔稳定性，不改变标称接口尺寸。
- [ ] S2-03：局部切出六个指扣。切削体限制在对应左右壁厚范围，禁止一根贯穿主体的长圆柱误切内部结构。
- [ ] S2-04：生成 6 mm 平板托盘；底部 45° 倒角向下内缩，保持上部定位外形尺寸；不用现有顶面侧斜角冒充底部倒角。
- [ ] S2-05：返回独立零件几何及装配变换。打印零件底面 Z=0，装配位置与打印位置分别表示。

- [ ] S2-07：建立截面、尺寸、连通性、网格闭合、体积和装配干涉测试；对共面处使用明确容差，不靠“体积大于零”替代拓扑验收。

建议模块：`src/lib/storage-stepped-model.ts`；沿用 JSCAD，复用现有几何原语。参考堆叠盒体的构造计划组织，但单独实现阶梯仓体规则。

### 验收标准

- [ ] 每种高度得到一个连通主体；三个托盘各为一个独立有效实体。
- [ ] 主体外尺寸、台面与托盘总厚度误差不超过 0.01 mm；圆弧离散相关测量按项目精度另记录。
- [ ] 下仓不串仓、底板完整；隔墙代表性截面符合 8 mm 规则。
- [ ] 指扣最低点和左右位置正确，能够看见承托边被切开的真实形状。
- [ ] 任一平板托盘装入任一阶均无正体积穿插，底面落到承托平面，顶面齐平。
- [ ] 居中及侧向极限位置的接触宽度与第 3 节一致；避开指扣的代表性截面测量留档。
- [ ] 独立导出样件底面为 Z=0，无悬空零件、异常薄片或开口网格。

出口条件：两种主体与一个通用平板的结构验证通过。可启动公差样件试装；承重结论仍待实物测试。

## 7. 阶段 3：功能托盘、预设和布局导入

目标：托盘外部接口固定，内部支持预设及自由槽位。

### 开发任务

- [ ] S3-01：实现五个预设，保存生成后的槽位尺寸快照与坐标；用项目 `slot-definitions.ts` 的实际槽径，禁止固定叠加对话示例中的 0.6 mm 公差。
- [ ] S3-02：32 mm 候选采用五加五交错布局，计算完整槽形边界与槽间距离；布局尺寸不能仅根据标称直径判断。
- [ ] S3-03：支持圆槽、椭圆槽、旋转、增删移动、规格替换和复制到其他阶；空槽列表按平板处理。
- [ ] S3-04：固定托盘边界内校验槽位越界、互相干涉、最小边距；修改尺寸后不自动放大托盘适应布局。
- [ ] S3-05：复用槽形与底孔构造计划。默认建议关闭底孔，槽深暂按 3 mm；启用磁铁桩孔或磁吸底孔时逐项校验厚度、孔间及边缘冲突。
- [ ] S3-06：保持 6 mm 总厚度，验证槽底厚、孔深及底部倒角的组合；孔切削仅作用于所属托盘。
- [ ] S3-07：实现显式“导入托盘布局”。首版接收现有 custom 模式槽位参数；保留槽形和相对坐标，转换位置须有预览及位移说明，不缩放槽径。
- [ ] S3-08：对不支持的源模式、超界布局、无有效槽位或非法参数给出具体报告；不能将 stepped 文件整体自动转换为收纳主体。
- [ ] S3-09：取得用户已验证布局后增加独立回归样本，记录来源；缺失时预设仍标为候选推导。

### 验收标准

- [ ] 五个预设分别生成 0/10/10/10/5 个槽，实际外尺寸和总厚度始终一致。
- [ ] 对槽位使用几何边界与最小距离校验；候选 32.4 mm 槽径、5 mm 槽间距、3 mm 边距的交错布局可容纳，精确坐标由算法输出留档。
- [ ] 默认磁铁桩孔示例满足 `3 mm 槽深＋2 mm 孔深＋1 mm 底壁=6 mm`；超限输入被阻断，托盘不被抬高。
- [ ] 修改或复制某阶后，其他阶保持各自参数；撤销可恢复复制前内容。
- [ ] 导入实际槽位快照往返不改变尺寸，必要平移不改变相对位置；超界时无静默裁剪。
- [ ] 每个有效托盘为一个闭合实体，底孔及槽底截面符合构造计划。

出口条件：功能托盘能够独立生成并校验；精确复现实测布局是否完成单独报告。

## 11. 风险处置与回滚边界

| 风险 | 处理方式 | 验证与回滚边界 |
| --- | --- | --- |
| 承托边过窄 | 先试装；优先调整接口以下的承托材料 | 保持托盘接口时复测仓容与截面；若改变接口，版本化记录 |
| 磁孔要求更厚托盘 | 阻断冲突组合，调整槽深或孔参数 | 禁止暗改 6 mm；共享底孔规则回归 |
| 大托盘翘曲 | 记录材料及切片条件，完整件打样 | 调整制造参数不伪装成代码修复 |
| 新模式遗漏持久化分支 | 类型检查、目录和往返测试 | 按阶段提交；共享接入点可独立回退 |
| 缓存或坐标混淆 | 独立零件身份、快照指纹及装配变换 | 对比单件导出、装配和提起状态 |
| 用户实测布局尚未提供 | 候选布局注明来源，保留显式导入 | 不阻断通用开发，不标记精确复现完成 |

每阶段以独立可审查提交组织。正式发布前不暴露无法完整使用的入口。回滚新模式实现时保留已保存的新模式参数和草稿数据，不批量删除或强转为旧阶梯；旧版本不能读取新模式应明确说明。仅为回滚而长期保留两套建模后端不在本计划范围。
