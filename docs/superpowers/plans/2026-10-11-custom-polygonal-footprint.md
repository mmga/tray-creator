# 自定义模式直边包络开发计划

日期：2026-10-11

状态：代码已实现并分任务提交；自动化与页面验收通过，实机打印、外部切片及浏览器连续拖动性能尚未验证。

目标：在自定义模式增加“直边包络”，根据凹槽布局自动生成包含全部凹槽及边界间距的凸多边形底板，边数自动变化。

## 一、需求与实施边界

用户已确认希望“自动包住凹槽，边数随布局变化”。本计划沿用探索方案：采用凸多边形，第一版生成一整块连续底板。

| 场景 | 第一版行为 |
| --- | --- |
| 普通三角分布 | 生成三角形；尖角保护可能增加截角边 |
| 普通四角分布 | 生成四边形 |
| 更多外围凹槽 | 自动形成多边形，内部槽位不直接增加边数，但仍参与外缘包含计算 |
| 单槽、双槽、中心重合或近似共线 | 使用包含最终槽形及边距的轴对齐矩形 |
| L 形等存在凹口的分布 | 填平凹口，保持凸多边形 |
| 远距离凹槽 | 仍生成一整块，槽位之间填充实心材料 |
| 无槽位 | 轮廓结果为空、实体数为 0；沿用现有无槽生成／导出交互，不新增空白多边形功能 |

第一版不增加指定边数、手动顶点编辑、凹多边形、多实体断连、侧面斜角、固定外尺寸或阶梯直边模式，也不新增依赖。底板厚度、凹槽深度、底孔结构继续使用现有能力。

开发中用户追加并确认两项需求：复用圆角半径生成顶点圆弧，0 保留尖角，实际半径不超过边距；明确显示忽略圆角的实际边数。圆角通过“剩余边距的安全内核 + 向外圆弧”实现，离散顶点使用圆弧外切线交点，避免切进凹槽或减少边距。边数取圆角前有效边数，计入尖角保护新增边，不计圆弧面片。用户提供的十槽样例实测为 5 边形，4mm 圆角后的外尺寸为 169.4 × 172.6mm。

追加折角识别辅助：二维直边包络显示金色小圆点，每个有效折角一个，数量与边数一致；尖角标记顶点，圆角标记圆弧中部。标记随工作轮廓更新，屏幕尺寸保持稳定，不拦截编辑操作，也不进入模型或导出文件。十槽样例的自动测试覆盖五个标记及其轮廓位置；普通单槽布局已在生产页面验收四个标记。相关回归共 101 项通过，类型、规范、构建及打包检查通过；十槽文件的浏览器导入未获许可，未重试该导入。

“自动适配”不承诺最小面积。目标是边缘清楚、边距安全、结果稳定；超出打印尺寸时沿用现有尺寸提示。

## 二、现有链路与复用原则

当前调用关系：

```text
CustomLayoutParams
  → projectCustomContouredFootprintInput
  → constructContouredFootprints
  → 主线程会话内的轮廓状态
      → 二维画布轮廓
      → 尺寸／结果摘要／底孔校验
  → Worker 内按同样输入重新构造
      → createCustomTrayModel 拉伸、挖槽、挖底孔
      → 三维预览／体积／STL
```

复用 `ConstructedContouredFootprint` 的几何、外轮廓、边界、面积、实体数和包含校验契约。直边算法只增加一种二维构造策略，不建立另一套三维建模器，不重写画布。

主线程和 Worker 分别调用同一个纯构造函数；不传输包含函数的轮廓对象，不新增跨任务缓存。构造失败沿用持续错误、阻止生成与导出、允许继续编辑和保存草稿的处理。

实现前先检索所有 `footprintStyle`、`contoured` 和相关函数调用者。工作区已有未提交修改，尤其 `src/lib/param-normalization.ts`、`src/components/panels.test.tsx`；不得覆盖或混入无关变更。用户随后明确授权逐任务实施并提交，本轮按任务提交，重叠文件只暂存功能对应的差异块。

## 三、数据契约与样式规则

### 3.1 模式类型

保留共享 `BaseplateFootprintStyle = "rectangular" | "contoured"`，新增自定义模式类型：

```ts
export type CustomBaseplateFootprintStyle =
  | BaseplateFootprintStyle
  | "polygonal";
```

`CustomLayoutParams.footprintStyle`、`CustomTrayFootprint.footprintStyle` 和 `CustomTrayResultProjection.footprintStyle` 改用该类型。阶梯参数继续使用原类型，避免共享枚举扩展后被阶梯代码误认为弧形贴合。

自定义模式统一通过 `resolveCustomFootprintStyle` 解析三种值；只有 `rectangular` 使用矩形构造，`contoured` 与 `polygonal` 都消费派生轮廓。不要把“非弧形”当成“矩形”。

轮廓请求增加可选构造策略字段，例如 `constructionStyle?: "contoured" | "polygonal"`，缺失保持现有弧形算法。该字段仅用于运行时构造，不重复写入持久化参数。

### 3.2 参数生效范围

| 参数 | 直边模式 |
| --- | --- |
| 槽位最终尺寸、位置、旋转、椭圆外扩和轮廓指数 | 生效 |
| 槽间距 | 保持现有槽位操作与碰撞语义；边距联动时影响外边界 |
| 边界间距 | 生效；默认继续跟随槽间距 |
| 底板厚度、凹槽深度、底孔结构 | 生效 |
| 固定尺寸选择、托盘长宽 | 休眠并保留，不限制直边底板 |
| 圆角半径 | 生效；实际半径不超过边距，0 保留尖角 |
| 侧面斜角、平滑半径、断连距离 | 休眠并保留 |
| 堆叠盒体 | 不支持；切入直边模式时关闭，保留盒体其他配置 |

直边请求不进入现有槽群连通算法，不能借用 `smoothingRadius` 决定连通性。投影时将休眠的平滑、断连输入归为中性值，避免其影响轮廓和缓存身份。

切换样式不得改变槽位位置、尺寸、数量，不删除休眠参数；切回矩形或弧形时恢复各自设置。盒体启用与非矩形样式互斥的校验同时覆盖面板、参数更新动作和导入归一化。

### 3.3 持久化与旧文件

- 自定义导入允许 `polygonal`；缺失或未知值沿用当前矩形默认值及导入报告机制。
- 阶梯导入不接受 `polygonal`，沿用已有未知样式归一化和报告规则，不偷偷启用新功能。
- 参数文件与草稿只保存样式和已有参数，不保存派生顶点、几何或运行时缓存。
- 继续使用当前参数产物格式版本；新增枚举值不要求迁移旧文件。兼容承诺是新版本读取旧数据，不承诺旧程序正确读取新样式。
- 核查编码器、快照、草稿读写是否原样保留新枚举；能自然透传的模块只补验证，不增加适配层。

## 四、几何算法

### 4.1 主要方向与直边位置

1. 通过 `getFreeSlotProfileGeometry` 获取最终槽形，沿用槽位到轮廓输入的投影，不使用名义直径代替最终槽宽。
2. 对槽位中心按坐标排序、去重并求凸包，仅用于确定主要边方向，不直接作为底板顶点。
3. 去除中心凸包中冗余共线点，得到有序单位外法线。
4. 对每个外法线，根据所有凹槽的完整最终外缘计算支撑直线，再加边界间距。
5. 对这些半平面求交，得到逆时针、闭合、无自交的凸多边形，使用现有 `geom2.fromPoints` 生成二维几何。

对单位外法线 `n`，直线写作 `n·x ≤ d`：

```text
d = max(各槽位在 n 方向上的最外侧投影) + boundarySpacing
```

必须遍历所有槽位：中心位于内部但尺寸更大的槽位也可能决定外边界。

### 4.2 圆形与旋转椭圆的安全包含

圆形使用最终半径求支撑值。椭圆包含现有超椭圆轮廓：先将外法线转入槽位本地坐标，再计算外缘投影，最后加入等距外扩量。

对于项目当前使用的轮廓指数 `p > 1`，半轴 `a、b`，本地法线 `u、v`，可使用以下解析支撑式：

```text
q = p / (p - 1)
槽位支撑值 = n·center
           + ((a·|u|)^q + (b·|v|)^q)^(1/q)
           + outerOffset
```

现有共享校验只要求指数大于 0。对 `0 < p ≤ 1` 的历史或直接输入，直边策略使用槽位本地矩形的保守支撑值 `a·|u| + b·|v|`，再加入中心投影及外扩，不套用上述解析式；不收紧旧弧形路径的输入规则。其余情况做数值稳定处理，圆形不读取无效的椭圆指数。

需特别处理现有建模分支：`src/lib/model-utils.ts` 的 `createOffsetSlotShape` 在 `outerOffset ≤ 0` 时使用标准椭圆，即 `p = 2`；画布采样仍可能使用槽位记录的指数。第一版不修改其他模式的槽形语义，直边支撑值在零外扩时取“记录指数的槽形支撑值”和“标准椭圆支撑值”中的较大者，同时容纳现有二维槽形和实际三维挖槽。退化矩形也由这组安全支撑值计算，不调用可能低估真实挖槽边界的采样外接框。增加 `p = 1.5、2、3` 且外扩为 0 的专门样例。若以后统一槽形语义，应作为独立修正覆盖相关模式。

不得仅取稀疏采样点最大值作为连续曲线安全边界，以免边距不足。用独立的密集轮廓采样、解析圆形案例以及实际三维挖槽几何验证支撑计算。

### 4.3 退化、尖角与确定性

- 少于三个不同中心或近似共线时，使用所有最终槽形的轴对齐外接矩形加边距；不能只包中心。
- 不通过对最终底板顶点做普通折线简化来减边，避免向内切入安全轮廓。若合并边方向，必须重新求全体槽位的支撑直线。
- 过小内角通过增加一条外侧支撑边截角；新增边仍按所有槽位求支撑，不能直接裁掉顶点后假定安全。
- 初始尖角阈值建议为 `20°`：按环绕顺序检查相邻外法线的夹角，超过 `160°` 时插入该角区间的角平分法线。以展开后的法线角度中点计算方向，避免接近反向的单位向量相加产生数值不稳定。原正常凸包的法线间隔小于 `180°`，每个原间隔最多补一条即可满足方向约束，随后统一重算支撑值与交集，不设无界迭代。
- 最终断言多边形内角不小于 `20°`（允许角度数值容差），且新增边不破坏安全包含。固定回归样例：圆槽中心 `(0,0)、(100,0)、(2,20)`、最终半径 `5mm`、边距 `2mm`；尖角处理后必须至少有四条有效边，XY bounds 落在 `[-20,120] × [-20,40]mm` 内，且包含三个扩大至 `7mm` 的圆。该样例不应进入近共线矩形分支。
- 近共线判定采用与布局尺度有关的容差。上述数值是实施起点，需在几何样例阶段记录最终取值与理由，不开放新用户配置；不能为让测试通过而降低包含要求。若最终交集仍有无法解释的极小内角，返回构造错误，不以反复截角掩盖错误。
- 位置排序、共线处理、边方向顺序和顶点起点规范化必须确定；交换槽位数组顺序或更换 ID 不应改变几何。
- 形状变化不得依赖上一帧历史。同样参数在导入、刷新、主线程和 Worker 中必须得到等价结果。
- 非空输入出现无效数值、无界交集、非正面积或无法安全包含时，返回显式构造错误，禁止输出残缺托盘。

对直边结果的圆形孔包含校验优先直接使用支撑半平面：每条边均满足 `n·center + radius ≤ d`。避免现有圆周离散采样遗漏靠近斜边的越界。

## 六、验收矩阵

| 类别 | 必测样例 | 通过标准 |
| --- | --- | --- |
| 基本形状 | 等尺寸圆槽三角／四角／五角分布 | 受尖角保护以外，边数符合外围方向；边缘为直线 |
| 尺寸与旋转 | 不同直径、内部大槽、旋转椭圆、超椭圆和外扩 | 任一边都容纳完整槽形及边距；边距不重复叠加 |
| 零外扩槽形 | `p = 1.5、2、3` 且外扩为 0 | 同时包含画布槽形和实际三维挖槽，不沿用不安全的指数假设 |
| 退化输入 | 空、单槽、双槽、重合中心、近共线 | 无异常；空结果或约定矩形，面积和 bounds 合法 |
| 尖角保护 | 扁长三角及极小夹角 | 无过长尖刺；截角后仍满足全部包含约束 |
| 连通语义 | L 形、远距离槽位 | 凹口填平；非空输出一个连续 body，不受平滑／断连值影响 |
| 几何质量 | 大小尺度、负坐标、边界上的圆孔 | 凸、闭合、无自交、正面积；孔相切可判定，越界可阻止 |
| 一致性 | 重排槽位、改 ID、主线程与 Worker | bounds、面积、几何轮廓在数值容差内等价 |
| 参数生命周期 | 三样式切换、拖动、取消、撤销、导入 | 槽位不被移动；参数保留；无旧轮廓残留 |
| 生成与导出 | 带凹槽和磁吸底孔的三角／多边形 | 模型正体积、底壁和孔深正确；STL 可由切片软件读取 |
| 数据兼容 | 旧矩形／弧形文件、直边 JSON 和草稿往返 | 旧默认不变，新样式及休眠配置保留 |
| 导出竞争 | 预览后改参数、导出期间继续编辑 | 不导出过期模型；文件名、STL、JSON 对应同一快照 |
| 其他模式 | 阶梯两种样式、网格、转换底座 | 不新增直边入口，原有测试和行为保持 |

几何包含测试以半平面约束为主，线性误差上限目标为 `1e-6 × max(1, 布局尺度)` mm；尺寸展示与现有 0.1mm 舍入保持一致。若实际数值库要求更宽容差，须记录原因并保持“边界误差只允许向外”的安全约束。

## 七、风险与回滚边界

- 凸包会填平凹口，远距离布局会增加耗材；通过样式说明和真实尺寸提示明确表达，不自动缩短槽距。
- 中心凸包决定方向，不能保证全局最小面积；所有槽形仍决定支撑位置，安全包含优先。
- 零外扩椭圆存在既有二维／三维槽形差异；本功能采用保守外包保证安全，不声称已修复该历史槽形问题。
- 近共线判定和尖角截边可能使拖动跨阈值时边数变化；用连续拖动样例验证，避免依赖历史状态造成导出不一致。
- 新样式被旧程序导入时可能归一化为矩形；发布说明需说明新文件应由支持直边模式的版本读取。
- 若发布后撤回，通过版本控制回退本功能的完整代码边界；回退前保留直边 JSON／草稿备份，不能声称旧版本仍能还原其形状。
- 不删除、不自动迁移用户已有草稿，不回滚工作区中其他功能的未提交修改。
